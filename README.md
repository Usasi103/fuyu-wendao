# 《浮屿问道》—— 开源单机修仙挂机游戏

一款融合 **《寻道大千》（砍灵树高频开箱 + 流派词条对抗 + 渡劫飞升）** 与 **《疯狂水世界》（浮岛仙居建设 + 3 级自动化演化 + 小队推图）** 的 2D 实时动画修仙放置游戏。

> **设计原则**：纯单机护肝爽游、无任何商业化氪金套路、核心数值公式与渲染层完全解耦、GPL-3.0 开源。

---

## ✨ 核心玩法与画面特色

* **16/32-bit 统一国风像素美术（PixiJS Nearest-Neighbor）**
  * 浮岛洞天、战斗秘境、7 种宗门仙建、4 帧像素动画主角/灵兽/巡逻弟子与妖兽全部统一为高对比度像素美术，视觉风格浑然一体。
* **浮屿洞天沙盘经营（6×4 可扩建地块 + 弟子守岛）**
  * **自由开垦与筑造**：点击像素浮岛任意地块，消耗仙建蓝图开垦荒崖并自由布局聚灵玄阵、瑶池灵泉、紫金丹炉、百草药田、神兵锻造坊、九霄雷塔等建筑。
  * **太古灵树砍树开箱**：操控像素剑修挥砍建木灵树，木屑与品质光球四溅；支持自动伐木与保底机制。
  * **宗门弟子巡逻 & 妖兽攻岛**：招募青云药童、玄铁炼徒等巡逻加产速，抵御周期性妖兽攻岛赢取玄铁与蓝图。
* **秘境星图探索（7×5 战争迷雾 + Roguelite 三选一）**
  * 步步揭开迷雾方格，触发灵草采集、古修宝箱、云游仙商、随机奇遇、🗿机缘神坛三选一肉鸽赐福与镇域妖王 Boss。
* **九宫五行策略战斗 & 控火炼丹锻造**
  * **3×3 九宫站位 + 五行生克**：前中后排索敌与 `金→木→土→水→火→金` 1.3× 克制增伤，Boss 蓄力大招预警提示。
  * **本命法宝灵力大招**：蓄满 100 怒气手动或自动祭出诛仙剑阵 / 混元金钟 / 九幽噬魂幡逆转战局。
  * **控火炼丹 & 神兵锻造**：药田收草药，在炉火控温小游戏中定格极品丹药；用秘境玄铁重铸升阶本命法宝。
* **跨设备云存档 & 单机友好功能**
  * `1x / 2x / 5x` 时间倍速 + 时空沙漏 + 离线挂机结算 + JSON 导入导出 + Node.js `/api/save/:key` 跨浏览器云存档。

## 📐 核心数值公式架构

所有核心数值均位于 [`src/core/formulas.ts`](src/core/formulas.ts)：

1. **境界成长曲线**：`Attr(T, s) = Base * 2.55^T * (1 + 0.12 * (s - 1))`
2. **修为经验需求**：`Exp(T, s) = 90 * 3.45^T * 1.14^(s - 1)`
3. **护甲减伤与保底**：`Damage = max(0.08 * Raw, Raw * ATK / (ATK + 1.25 * DEF))`
4. **流派对抗抵消**：`ActualRate = Clamp(SelfTrait - EnemyAntiTrait, 0, 0.80)`（暴击、连击、闪避、吸血、击晕均遵守对抗法则）
5. **建筑产出与消耗**：
   * 产出：`Rate(lv) = R0 * (1 + 0.3 * (lv - 1)) * 1.14^(lv - 1) * (1 + 0.06 * HighestStage)`
   * 消耗：`Cost(lv) = C0 * 1.42^lv`

## 🚀 VPS 部署与手机端游玩指南

本项目是纯前端静态应用（存档保存在玩家浏览器 `localStorage` 中，并支持 JSON 跨设备导入/导出），非常适合部署在任何轻量级 VPS 上供电脑和手机随时访问。

### 方式一：Docker 一键部署（推荐，自带跨浏览器/跨设备云存档后端！）
```bash
# 在 VPS 上拉取仓库后执行（持久化保存云端存档到 ./fuyu-saves 目录）
docker build -t fuyu-wendao .
docker run -d --name fuyu-wendao -p 8080:80 -v $(pwd)/fuyu-saves:/app/data/saves --restart unless-stopped fuyu-wendao
```
放行防火墙 `8080` 端口后，手机浏览器访问 `http://你的VPS公网IP:8080` 即可游玩！在游戏右上角设置里输入同一个**仙途口令**，即可在电脑浏览器和手机浏览器之间无缝同步进度。

### 方式二：Nginx 托管静态构建产物
1. 本地或 VPS 上运行 `npm run build` 生成 `dist/` 目录；
2. 将 `dist/` 上传到 VPS（如 `/var/www/fuyu-wendao`），参考仓库内的 [`nginx.conf`](nginx.conf) 配置站点即可。
3. 手机端建议在浏览器中选择 **“添加到主屏幕”**，可获得接近原生竖屏手游的全屏沉浸体验。

## 🌐 GitHub Pages 自动部署

仓库已内置 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)：
1. 将代码推送到 GitHub 仓库的 `main` 分支；
2. 在仓库 `Settings -> Pages -> Source` 选择 **GitHub Actions**；
3. Action 会自动执行测试、打包并发布可直接在浏览器游玩的网页版！
